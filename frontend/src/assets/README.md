# Frontend assets

The remaining files here are original or simple project graphics (logo, placeholders, sign-in and sign-up artwork) and test screenshots created for this project.

In October 2026 the 2023 course screenshots that contained third-party artwork (cartoon characters, stock photos and clipart) were removed from the current version. On 15 Oct 2026, 23 flagged historical image blobs and four compiled artifacts embedding them were also removed from the rewritten Git history. Current original project illustrations were retained; see the root README for the cleanup record and cache limitations.

Demo photos and avatars shown on the live site are AI-generated illustrations of imaginary families. They are hosted on Cloudinary and are not stored in this repository.
